## Не подтверждено проверкой
- Сквозной сценарий в браузере пройден частично (запуск сайта, запись о здоровье). Не проверены: второй участник семьи, цели, главная панель, блокировка входа после 5 ошибок, телефон (адаптив проверен только по разметке).

## Известные ограничения (низкие замечания аудитов)
- Защита входа считается по email, не по IP; нет ограничения частоты регистрации и подбора кода приглашения — добавить перед публичным запуском.
- Лимит 20 целей без блокировки (возможна 21-я при одновременных запросах).
- Форма очищается после ошибки валидации; в списках только 30 последних записей; нет интеграционного теста изоляции семей на реальной БД.
- Сохранение записи занимает 1–3 секунды из-за удалённой БД: для реальных пользователей перенести базу в Европу (Frankfurt).
- Решения пользователя: роль «взрослый» при вступлении по коду свободная; достижения не отзываются; освободившийся лимит не пересчитывает поздние записи.
