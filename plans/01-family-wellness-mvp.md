# План 01: Family_Wellness — первая версия сайта

## Context
Проект пустой: есть только `goal.md`, `AGENTS.md`, skills и субагенты. Нужен сайт с регистрацией, общей семейной панелью, учётом активности, питания и здоровья и геймификацией (баллы, уровни, достижения, семейные цели). Рабочий проект, данные о здоровье, в том числе детей. Стек не задан, выбираю простой и современный.

## Стек (допущение, можно изменить)
- Next.js (App Router) + TypeScript: фронт и бэкенд в одном проекте.
- Tailwind CSS: адаптивная вёрстка под телефон и компьютер.
- Prisma + PostgreSQL (локально можно SQLite): общая БД семьи.
- Auth.js (логин и пароль), пароли хешируются bcrypt.
- Vitest: тесты логики баллов, уровней, достижений и API.
- Секреты только в `.env` (уже в `.gitignore`).

## Модель данных (кратко)
Family, User (роль: взрослый/ребёнок, привязан к семье), ActivityLog, MealLog / WaterLog, HealthLog (вес, сон, самочувствие), PointsEvent, Achievement / UserAchievement, FamilyGoal.
Вход в семью: создатель регистрирует семью и получает код приглашения, остальные регистрируются по коду.

## Этапы
1. **Каркас.** Инициализация Next.js, Tailwind, Prisma, схема БД, базовый layout, Vitest.
2. **Аккаунты и семья.** Регистрация, вход, создание семьи, код приглашения, профили членов семьи, защита страниц.
3. **Учёт.** Формы и списки: активность, питание и вода, показатели здоровья. Видимость: данные семьи видны членам семьи.
4. **Геймификация.** Правила начисления баллов за записи, уровни по сумме баллов, набор достижений (серии дней, первые записи и т. п.). Логика в отдельном модуле, покрыта тестами.
5. **Семейные цели и панель.** Создание целей (например, «300 км за месяц»), общий прогресс, дашборд семьи: баллы, уровни, достижения, прогресс по целям.
6. **Финиш.** Адаптив под телефон, проверка безопасности (пароли, доступ только к своей семье, ввод данных), README с запуском.

Каждый этап: implementor, затем test-writer, test-runner, в конце auditor (skill `implement`).

## Критические файлы
`prisma/schema.prisma`, `src/lib/gamification.ts` (баллы, уровни, достижения), `src/app/` (страницы и API), `src/auth.ts`, `.env.example`.

## Проверка
- `npm test`: тесты геймификации и API проходят.
- `npm run dev`: вручную пройти сценарий из критериев готовности: регистрация, добавление членов семьи, записи активности/питания/здоровья, рост баллов и уровней, достижения, цели и панель.
- Проверка с экрана телефона (адаптив).
- Проверка, что пользователь не видит данные чужой семьи.
- Отчёт аудитора в `plans/audit-01-*.md`.
